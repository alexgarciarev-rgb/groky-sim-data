# groky-sim-data

Datos diarios de **Groky Sim** (simulador NBA y fútbol).

- [`latest.json`](./latest.json) — última jornada NBA publicada
- `YYYYMMDD.json` — NBA de esa fecha (hora America/Mexico_City)
- [`soccer_latest.json`](./soccer_latest.json) — última jornada de fútbol (hoy + mañana)
- `soccer_YYYYMMDD.json` — fútbol de esa ventana

Raw (para la app):

- https://raw.githubusercontent.com/alexgarciarev-rgb/groky-sim-data/main/latest.json
- https://raw.githubusercontent.com/alexgarciarev-rgb/groky-sim-data/main/soccer_latest.json

Generado por `/workspace/nba_sim/publish.sh`. No contiene código ni secretos.
