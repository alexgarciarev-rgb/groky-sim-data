# groky-sim-data

Datos diarios de **Groky Sim** (simulador de props y totales NBA).

- [`latest.json`](./latest.json) — última jornada publicada
- `YYYYMMDD.json` — archivo de esa fecha (hora America/Mexico_City)

Raw (para la app):

- https://raw.githubusercontent.com/alexgarciarev-rgb/groky-sim-data/main/latest.json
- https://raw.githubusercontent.com/alexgarciarev-rgb/groky-sim-data/main/YYYYMMDD.json

Generado por `/workspace/nba_sim/publish.sh`. No contiene código ni secretos.
